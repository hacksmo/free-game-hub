# Free Game Hub (CARCADE)

Android 车机 / 手机横屏游戏中心：打开即玩，全部游戏支持手柄，全面中文化，离线可玩。

## 当前版本 V1.10

- **车机性能：图片资源瘦身（卡顿主因）**：游戏封面原为 1664×2496 JPEG（约 1.2MB/张），车机屏上实际只显示约 316×475px——解码后 10 张封面就占约 166MB 位图，是「778G 也卡」的真正原因。全部改为 **720×1080 WebP**（12MB → 0.7MB），全部图片加 `decoding="async"` + 首屏图 `fetchPriority="high"`、非首屏 `loading="lazy"`；前端资源 89MB → 28MB，安装包 **69MB → 22.8MB**，画面观感不变
- **车机诊断面板（无需 root/ADB）**：设置页新增「车机诊断」，直接显示系统视角数据——音频焦点/媒体会话、**全部输出端口（车机多路为 BUS 通道）**、当前活跃播放被路由到哪、系统是否识别手柄、内存与 BYD 组件列表，并探测本机是否存在 BYD 专属音频通道接口；「导出诊断报告」写入剪贴板即可粘贴给开发者，用于定位「无声 / 进不了游戏模式 / 连手柄泛白」
- **车机无声修复（音频路由）**：依据真车诊断报告——焦点已授予、媒体会话已激活且存在活跃播放流，但车机把第三方媒体流默认路由到**不接喇叭的通道**（输出列表里并列着「听筒/通话」口）。本版做三件事：①注册 **MediaBrowserService** 让车机 CarAudioService 把应用识别为媒体源并分配扬声器 zone；②新增**音频输出路由**：常驻 MEDIA+CONTENT_TYPE_MUSIC 静音流并 `setPreferredDevice` 显式绑定通道，读取**实际路由设备**；③设置页「车机诊断」新增**音频输出通道选择器**，车机上无需 ADB 即可手动切通道（默认锚定内置扬声器）。另修正手柄枚举（改用公开 API，此前真车显示 0 个是隐藏 API 被拦）
- **详情页一屏化**：游戏详情重做为横向三栏（海报｜信息｜预览），一屏显示完整、无需上下滚动；简介自适应行数、规格压成 chips、版本移顶栏、安装状态做海报徽标；1280×720 / 1024×600 / 1920×1080 三档分辨率实测均不溢出，保留三套主题与手柄导航
- **画面缩放锁定**：viewport 锁 `maximum-scale=1 / user-scalable=no` + WebView 关闭缩放支持/控件/overview 模式，页面恒 100% 贴合屏幕，修复车机「一会全屏一会放大」的缩放漂移
- **通知单条化**：提示气泡改为「新替旧、单条显示」，修复「安装完成」与「返回大厅」两条提示在回大厅瞬间上下堆叠、遮挡封面的问题（实测中央封面始终精确居中）
- **详情按钮收敛**：开始游戏/收藏/移除按钮缩小（高 34–40px）、不再沉底，紧跟简介/规格；保留上一版左对齐、舒展的排版
- **详情整组垂直居中**：信息栏内容组在栏内垂直居中（上隙≈下隙），修正「太靠上」；不改变左对齐与一屏布局
- **车机性能模式（默认开）**：针对弱车机滑动卡顿——去掉背景持续 Ken Burns 缩放动画（每帧重光栅化的最大元凶）、逐卡景深模糊、地面镜面倒影与中央大发光阴影，只保留静态缓存背景；卡片几何/透明度/交互不变，滑动更顺。设置页可一键关闭、恢复完整影院特效
- **归类为游戏**：`appCategory="game"` + `isGame="true"`，让车机把本应用识别为游戏类，争取游戏性能调度，并尝试规避车机连手柄时叠加的辅助蒙层
- **车机音频路由修复**：真车实测「焦点已授予、WebAudio 在运行却无声」，根因是 OEM 音频路由隔离；新增活动 **MediaSession**（STATE_PLAYING）把应用标记为媒体源，争取车机把 WebView 声音路由到扬声器
- **音频诊断增强**：诊断面板新增「媒体会话」状态 chip（焦点 / 上下文 / 媒体会话三项），真车无声可就地精准定位
- **惯性甩动浏览**：手指快速一拨即可连滚多张封面（速度投影 + easeOutCubic 吸附），慢拖跟手停在任意位置；拖拽期禁用过渡与景深模糊、逐帧只写合成器属性，144Hz 高刷屏跟手不卡；边缘橡皮筋阻尼回弹
- **大厅背景音乐 + 开机音**：进入软件播放温暖上行开机琶音；大厅自动循环播放内置合成波主题曲（克制音量、离线直服零网络请求）；进入游戏淡出暂停、返回大厅淡入续播；顶栏一个开关统管音乐与音效（参考 PS5/Xbox 主机式体验）
- **按钮文字真正居中**：去掉开始/下载等文字按钮左侧的小三角图标，纯文本水平居中；详情(左) · 下载/开始(中) · 收藏(右) 对称三列保持
- **卡内按钮对称布局**：详情(左) · 下载/开始(中) · 收藏(右)，等宽侧列三列网格，主按钮在封面内绝对居中
- **海报级封面**：10 款游戏全部换上定制电影感 key art——合成波竞速、雨夜霓虹悬疑、水墨仙侠、金色沙漠公路、废土机甲、深海荧光、像素太空射击……统一 2:3 竖版海报构图，画面不含文字，排版由大厅信息层承担；大厅 / 发现页 / 详情页同步焕新
- **信息做进封面卡片**：游戏标题 + 分类/手柄/体积眉题 + 开始/下载按钮 + 详情 + 收藏，全部收进中央封面底部的渐变信息层——封面即海报，海报即界面；删除卡下独立信息区，中央封面 52vh → **66vh** 巨幕化
- **CoverFlow 封面传送带大厅**：中央封面最大、左右 3D 透视 + 景深淡化 + 镜面倒影，背景随选中游戏切换；手柄左右切封面、A 直接开始，焦点自动跟随新封面
- **内置三套主题风格，软件内即时切换**：霓虹街机（默认）/ 琥珀工业 / 深空影院；顶栏调色盘入口 + 设置页主题区，重启后自动保持
- **10 款游戏**，全部支持手柄（标准映射）+ 触摸 / 键盘
- 应用 UI 与游戏界面全面中文化
- 离线可玩：游戏包本地加载，零互联网请求；离线包不再重复携带封面，APK 仅增约 4MB
- 手柄友好：大厅焦点导航、游戏中**长按 B 退出**（防误触）、设置页**手柄按键诊断面板**
- 车机 WebView 优化：实心顶栏、去模糊、滚动流畅
- **车机无声修复**（比亚迪 DiLink 7.0）：原生媒体音频焦点 + WebAudio 无手势解锁 + 设置页**音频诊断面板**

## 下载与安装

到 [Releases](https://github.com/hacksmo/free-game-hub/releases) 下载 `FreeGameHub-V1.10-debug.apk`（约 23 MB，比上一版瘦 67%）。

```bash
adb install -r FreeGameHub-V1.10-debug.apk
```

覆盖安装保留数据（versionCode 9 → 10）。包名 `net.hackmo.carcade`。旧版本 Release 原样保留，可随时回退。

## 版本历史

- **V1.10**：车机音频路由修复——注册 MediaBrowserService 成为车机媒体源（CarAudioService 分配扬声器 zone）+ 常驻静音媒体流显式绑定输出设备 + 设置页音频输出通道选择器（无需 ADB 可手动切）+ 手柄枚举改用公开 API
- **V1.9**：车机性能专项——游戏封面/截图全量转 WebP 并降采样（前端 89MB → 28MB，安装包 69MB → 22.8MB），全部图片异步解码与首屏优先；新增「车机诊断」面板（输出端口/BUS 通道、活跃播放路由、手柄识别、BYD 组件与音频接口探测、一键导出报告），用于定位车机无声 / 进不了游戏模式 / 手柄泛白
- **V1.8**：详情页排版按反馈回调——恢复上一版左对齐、舒展的一屏布局，按钮保持收敛（34–40px、不沉底、紧跟简介），并把信息栏整组在栏内垂直居中（修正「太靠上」）；三档分辨率实测上隙≈下隙、无裁剪
- **V1.7**：车机体验修复——性能模式（默认开，去背景持续动画/景深模糊/倒影，弱车机滑动流畅，可一键恢复特效）+ 归类为游戏（appCategory=game）+ MediaSession 音频路由修复 + 音频诊断「媒体会话」状态；详情页一屏化（横向三栏，三档分辨率不溢出）+ 画面缩放锁定（修复一会全屏一会放大）+ 通知单条化（修复回大厅提示堆叠遮挡封面）+ 详情按钮收敛（缩小/不沉底/紧跟简介）；移除「新手赛车」，内置游戏 11 → 10 款
- **V1.6**：惯性甩动浏览（快速一拨连滚多卡 + 高刷跟手优化）+ 大厅背景音乐与开机音（进游戏让位/返回续播/一键静音）+ 按钮去三角图标文字居中
- **V1.5.1**：卡内按钮对称布局——详情(左) · 下载/开始(中) · 收藏(右)，主按钮绝对居中
- **V1.5**：海报级封面（11 张定制 key art）+ 信息做进封面卡片 + 66vh 巨幕封面 + 焦点导航适配
- **V1.4**：影院级大厅精修——封面 52vh 主角化、背景压暗强暗角、倒影增强、开始按钮克制化、详情圆形图标化
- **V1.3**：CoverFlow 封面传送带大厅 + 三套主题即时切换（霓虹街机 / 琥珀工业 / 深空影院）；安装包瘦身约 88 → 76 MB
