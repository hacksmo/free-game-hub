# Free Game Hub (CARCADE)

Android 车机 / 手机横屏游戏中心：打开即玩，全部游戏支持手柄，全面中文化，离线可玩。

## 当前版本 V1.6

- **惯性甩动浏览**：手指快速一拨即可连滚多张封面（速度投影 + easeOutCubic 吸附），慢拖跟手停在任意位置；拖拽期禁用过渡与景深模糊、逐帧只写合成器属性，144Hz 高刷屏跟手不卡；边缘橡皮筋阻尼回弹
- **大厅背景音乐 + 开机音**：进入软件播放温暖上行开机琶音；大厅自动循环播放内置合成波主题曲（克制音量、离线直服零网络请求）；进入游戏淡出暂停、返回大厅淡入续播；顶栏一个开关统管音乐与音效（参考 PS5/Xbox 主机式体验）
- **按钮文字真正居中**：去掉开始/下载等文字按钮左侧的小三角图标，纯文本水平居中；详情(左) · 下载/开始(中) · 收藏(右) 对称三列保持
- **卡内按钮对称布局**：详情(左) · 下载/开始(中) · 收藏(右)，等宽侧列三列网格，主按钮在封面内绝对居中
- **海报级封面**：11 款游戏全部换上定制电影感 key art——合成波竞速、雨夜霓虹悬疑、水墨仙侠、金色沙漠公路、废土机甲、深海荧光、像素太空射击……统一 2:3 竖版海报构图，画面不含文字，排版由大厅信息层承担；大厅 / 发现页 / 详情页同步焕新
- **信息做进封面卡片**：游戏标题 + 分类/手柄/体积眉题 + 开始/下载按钮 + 详情 + 收藏，全部收进中央封面底部的渐变信息层——封面即海报，海报即界面；删除卡下独立信息区，中央封面 52vh → **66vh** 巨幕化
- **CoverFlow 封面传送带大厅**：中央封面最大、左右 3D 透视 + 景深淡化 + 镜面倒影，背景随选中游戏切换；手柄左右切封面、A 直接开始，焦点自动跟随新封面
- **内置三套主题风格，软件内即时切换**：霓虹街机（默认）/ 琥珀工业 / 深空影院；顶栏调色盘入口 + 设置页主题区，重启后自动保持
- **11 款游戏**，全部支持手柄（标准映射）+ 触摸 / 键盘
- 应用 UI 与游戏界面全面中文化
- 离线可玩：游戏包本地加载，零互联网请求；离线包不再重复携带封面，APK 仅增约 4MB
- 手柄友好：大厅焦点导航、游戏中**长按 B 退出**（防误触）、设置页**手柄按键诊断面板**
- 车机 WebView 优化：实心顶栏、去模糊、滚动流畅
- **车机无声修复**（比亚迪 DiLink 7.0）：原生媒体音频焦点 + WebAudio 无手势解锁 + 设置页**音频诊断面板**

## 下载与安装

到 [Releases](https://github.com/hacksmo/free-game-hub/releases) 下载 `FreeGameHub-V1.6-debug.apk`（约 80 MB）。

```bash
adb install -r FreeGameHub-V1.6-debug.apk
```

覆盖安装保留数据（versionCode 5 → 6）。包名 `net.hackmo.carcade`。旧版本 Release 原样保留，可随时回退。
